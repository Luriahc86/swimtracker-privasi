Kebijakan Privasi Swim Tracker

Berlaku sejak: 18 November 2026

Swim Tracker adalah aplikasi untuk mencatat latihan renang pribadi. Kebijakan ini menjelaskan data apa yang diolah aplikasi dan ke mana data itu disimpan.

Ringkasan

  • Tidak perlu akun atau login, dan kami tidak meminta nama, email, atau nomor HP.
  • Tidak ada iklan, analitik, atau pelacakan.
  • Data latihan disimpan di perangkat Anda dan dicadangkan ke server kami.
  • Kami tidak menjual atau membagikan data Anda kepada pihak mana pun.

Data yang Anda masukkan

Aplikasi menyimpan data latihan yang Anda isi sendiri: gaya renang, jarak, durasi, tanggal latihan, dan catatan opsional. Aplikasi tidak mengakses lokasi, kontak, kamera, mikrofon, file, atau data kesehatan dari aplikasi lain.

Tempat data disimpan

Data disimpan dalam database di penyimpanan internal perangkat Anda. Data tersebut terhapus bila Anda menghapus data aplikasi atau meng-uninstall aplikasi. Bila fitur cadangan Android di perangkat Anda aktif, sistem Android dapat menyertakan data ini dalam cadangan akun Google Anda, sesuai pengaturan perangkat Anda sendiri.

Penyimpanan di server

Saat perangkat terhubung ke internet, data latihan dikirim ke server kami sebagai cadangan. Pengiriman memakai koneksi terenkripsi (HTTPS).

Karena tidak ada login, aplikasi membuat ID acak saat pertama dibuka. Data Anda di server hanya dikaitkan dengan ID ini, bukan dengan nama, email, atau identitas lain. Server hanya memberikan data kepada perangkat yang membawa ID tersebut, sehingga pengguna lain tidak dapat melihat data Anda. Server juga mencatat sementara alamat IP pengirim request untuk membatasi penyalahgunaan (lihat bagian Menghapus data).

Bila aplikasi di-uninstall, ID tersebut ikut terhapus dan data di server tidak lagi dapat diakses dari perangkat mana pun.

Izin aplikasi

  • Internet: untuk mencadangkan data latihan ke server.

Anak-anak

Aplikasi ini tidak ditujukan untuk anak di bawah 13 tahun dan tidak dengan sengaja mengumpulkan data dari mereka.

Menghapus data

Menghapus catatan latihan di aplikasi juga menghapusnya dari server. Untuk menghapus seluruh data sekaligus, buka menu Data & privasi di halaman utama aplikasi lalu pilih Hapus data: semua catatan latihan Anda dihapus dari server dan dari perangkat. Bila aplikasi sudah terhapus dari perangkat Anda, penghapusan data di server dapat diminta lewat email di bawah dengan menyertakan ID perangkat yang tertera di menu tersebut.

Penghapusan lewat aplikasi berlaku seketika: catatan latihan dihapus permanen dari database server, bukan sekadar disembunyikan. Permintaan lewat email diproses paling lambat 30 hari setelah diterima. Untuk mencegah penyalahgunaan, server mencatat sementara alamat IP dan ID perangkat pengirim request beserta jumlah request-nya; catatan ini terhapus otomatis dalam waktu sekitar satu jam. Log teknis dan cadangan milik penyedia server (Supabase) dapat menyimpan salinan sementara sesuai masa simpan mereka, lalu terhapus dengan sendirinya.
